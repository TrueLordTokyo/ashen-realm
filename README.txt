THE DRENCHWOOD
A rain-soaked coastal forest for Roblox Studio.

This is the map only. No NPCs, no combat, no objectives.
Old trees, moss, a worn trail, a still pool, standing stones,
a cliff, and a grey sea. The rain does not stop.

It is the rainy cape-forest from that story, under another name
so Roblox does not take the place down.

OPEN IT
  1. Download Drenchwood.rbxlx from this repo (or AshenRealm.rbxlx, same file).
  2. Roblox Studio > File > Open from File.
  3. Wait. The Output window should say "Growing the forest".
     The ground is real terrain. There is no baseplate.
     Growing it takes a bit. Do not stop it halfway.
  4. When it says "Done", click the part named Lookout in
     Explorer (inside the Drenchwood folder) and press F to frame it.
  5. File > Save, so next time the forest is already there.
  6. Press Play to spawn on the western ridge and hear the rain.
     Walk east. The sea is that way. The pale trees are north.
     The standing stones sit by a pool near the middle.

The scripts that grow the map:
  ReplicatedStorage / MapBuilder
  ServerScriptService / BuildOnServer
  ServerScriptService / BuildInStudio   (runs in Studio, not just in Play)
